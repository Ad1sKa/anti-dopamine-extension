# Анти Дофамин: Блокировщик Shorts и Рекламы для YouTube

[![Поддержать автора](https://img.shields.io/badge/Поддержать-на%20Boosty-blue?style=for-the-badge&logo=boosty)](https://boosty.to/Ad1sKa)

Расширение для Chrome, которое возвращает контроль над YouTube. 
Оно полностью скрывает видео Shorts, а официальную рекламу заменяет на стильный черный экран с надписью «Тут могла бы быть ваша реклама». При этом кнопка «Пропустить» и управление плеером остаются полностью рабочими!

## ✨ Возможности
* **Полная блокировка Shorts**: Никаких вертикальных видео в ленте и рекомендациях.
* **Замена рекламы**: Рекламные ролики становятся черным экраном, звук выключается.
* **Счетчик попыток**: Расширение считает, сколько раз вы пытались зайти в Shorts.
* **Совместимость**: Работает на всех страницах YouTube.

## 🚀 Установка
1. Скачайте ZIP-архив из раздела **[Releases](https://github.com/Ad1sKa/anti-dopamine-extension/releases)**.
2. Распакуйте архив в любую папку.
3. Откройте в Chrome страницу `chrome://extensions/`.
4. Включите **«Режим разработчика»** (тумблер в правом верхнем углу).
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку, куда вы распаковали архив.
6. Готово! Зайдите на YouTube и наслаждайтесь тишиной.
